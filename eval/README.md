# 人工评测

`cases.json` 为人工编写的虚构最小样本，每条含预期注意点和禁止结论。不是律师审定的法律标准答案。

配置真实模型后逐条粘贴文本、使用真实分析，人工记录引用是否准确、是否遗漏预期注意点、是否出现无依据判断及禁止结论。特别检查“未发现”是否只限当前覆盖范围。

尚未运行真实模型评测；准确率、延迟和调用费用均为待测，不填写虚构分数。记录时间可用浏览器网络面板；费用以供应商实际 usage/账单为准，程序目前不估算费用。提示注入测试只能提供样本级证据，不能证明绝对免疫。

在 `results.csv` 中填写各样本结果，记录模型版本和评测日期，以便后续升级对比。

## 香港租约（REGION=hk）

`hk_cases.json` 有 11 条虚构样本，格式同上，额外字段为：

- `tool`：promises / compare，表示用哪个工具评测；
- `promises`：用于承诺对照的业主或代理说法；
- `paired_with`：用于临约与正式租约比较的另一份文字；
- `context`：例如 `output_language`。

样本覆盖：死约期内退租罚则、按金退还期限缺失、维修责任全推给租客、费用分担不清、收款人与出租人不一致、二房东未提业主同意、口头承诺、临约与正式租约不一致、提示注入、英文输出、OCR 漏字。

禁止结论统一包括：断言诈骗、判断身份真伪、判断按金扣减或收费是否合法、输出条例编号、认定口头承诺已构成租约。

结果填写在 `hk_results.csv`，目前全部是 `not_run`。香港版提示词尚未用真实模型评测，不填写任何准确率分数。

OCR 评测另见 `hk-ocr.md`。
