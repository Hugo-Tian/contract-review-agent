# 明约（香港版）· 项目说明草稿

> 用于 Hong Kong Techathon+ 的草稿，**尚未提交**。按评审四项（创新/技术、商业可行性、团队能力、社会影响，各 25%）组织。
> 文中没有使用任何市场、人数或纠纷数据；凡是需要数字的地方都标为“待验证”，并写明应去哪里查。

## 一句话

帮刚来香港、或尚未到港的留学生和新来港人士读懂住宅租约：哪些条款写明了、哪些没写、哪些和临约或口头承诺不一样，下一步该问什么、去哪里核实。每个结论都附租约原文。

## 1. 创新与技术

**要解决的问题**：租客常常人不在香港，也不熟悉本地租房惯例；合约多为英文或繁体中文，通常经地产代理或二房东签订。常见的坑包括：临约已有约束力、生约/死约与提前退租罚则、按金扣减与退还期限、差饷/地租/管理费由谁付、维修责任、二房东分租、收款人与出租人不一致、口头承诺没写进合约。

**技术做法（已实现，可演示）**：

- **原文可追溯**：租约按句切成编号片段，模型只能选片段编号，后端回填逐字原文并校验。伪造引用、条例编号、诈骗或合法性判断会被拦截并重试，失败就不展示。英文和繁体原文引用逐字保留；解释可选简体、繁体或英文。
- **不越界**：不判断业主身份真伪、租约效力或扣费是否合法。遇到收款人与出租人不一致等情况，只写出看到了什么、缺了什么，并建议用户自行核实（例如查册）。
- **工具链**：业主/代理承诺对照；按金与退租试算（Decimal 精度，展示算式，两种情景，不预设“市场惯例”）；签约前一次性支出；临约与正式租约比较；签约前核对清单（规则生成，不联网，每项附原文或注明未找到）。
- **隐私**：原文件不落盘，发送前本地脱敏（香港身份证、+852 电话、银行账号、卡号、带标签的姓名）。姓名替换为一致的化名，仍可比较收款人与出租人是否为同一人。发送前需用户明确同意。
- **工程**：同一代码库通过地区配置支持大陆培训合同版和香港租约版，大陆版输出逐字节不变；工作流用 openJiuwen SDK 编排；143 项后端测试和端到端测试。

**诚实说明的局限**：

- 香港法规库尚未建立：开发环境无法访问 eLegislation，系统不使用模型编写的条文。
- 本机 OCR 对繁体识别较弱（见 `eval/hk-ocr.md`）。
- 香港版提示词尚未用真实模型系统评测。

## 2. 商业可行性（全部为待验证假设）

| 假设 | 怎么验证 | 数据从哪里查（待验证） |
|---|---|---|
| 来港留学生和新来港人士对“看懂租约”有付费或使用意愿 | 访谈 15–20 名在港内地学生；在 2–3 个学生群做原型测试 | 非本地学生人数：大学教育资助委员会（UGC）统计、各大学 Facts & Figures；入境人数：入境事务处年报 |
| 租房纠纷足够常见，值得做事前预防 | 访谈学生会和宿舍办公室；整理匿名个案类型 | 消费者委员会投诉统计；地产代理监管局年报中的投诉数据；司法机构年报中的小额钱债审裁处案件数 |
| 可以通过大学学生事务处或住宿处、学生会、留学生社群合作推广，获客成本较低 | 接洽 1–2 所大学的学生事务或宿舍部门，试办租房讲座并附工具试用 | 合作方反馈与试用数据（自行收集） |
| 地产代理或租房平台愿意把它作为“签约前自查”工具接入 | 访谈 3–5 家中小型代理；评估利益冲突与中立性风险 | 访谈记录（自行收集） |
| 收入模式：学生免费，按次付费的深度报告，或面向机构的授权 | 原型阶段测试付费意愿 | 用户测试结果（自行收集） |
| 模型调用成本可控 | 统计每份租约的实际 token 用量和费用 | 模型供应商账单（程序暂不估算费用） |

风险：法律服务边界（必须持续强调不构成法律意见）、与代理合作时的中立性、个人数据保护、OCR 识别质量。

## 3. 团队能力（待填写）

- 成员、分工与背景：待填写。
- 已完成的工作可以用仓库提交记录、测试和演示来证明；不在这里写无法核实的经历。

## 4. 社会影响

- **对象**：初到香港、信息不对称较大的租客。他们往往人不在香港就要先付订金，而且不熟悉繁体或英文合约。
- **作用**：在签约前把风险点、缺失条款和需要核实的事项摆出来，并指引到官方渠道（差饷物业估价署租务咨询、地产代理监管局、土地注册处查册、消费者委员会、小额钱债审裁处、免费法律咨询计划）。不替代专业意见。
- **可以衡量的指标（待设计）**：试用者在签约前提出的问题数、核对清单完成率、事后纠纷自述。均需在试点中收集，目前没有数据。

## 附：演示建议（3 分钟）

1. 导入虚构英文租约 → 报告指出死约罚则、按金退还期限缺失、收款人与出租人不一致，每项附原文。
2. 业主/代理承诺对照：粘贴“家电坏咗业主会包修”，显示与维修条款不一致。
3. 临约与正式租约比较：显示“14 天内退按金”和“业主修家电”在正式租约中被改动。
4. 按金与退租试算、签约前核对清单、求助渠道。

所有演示材料都是虚构的，位于 `examples/hk/`。
