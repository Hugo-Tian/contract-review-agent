# 明约 · 合同阅读工作台

面向中国大陆培训、求职辅导合同的单用户本地应用。用日常中文解释条款，保留原文引用，提供沟通草稿。需求原件位于 contract-agent-mvp-prompt.md；本次用户授权扩展了原MVP的六项工具。

## 启动

双击桌面“启动合同检测助手.bat”。它调用项目 launch.ps1，后台启动并检查服务，地址为 http://127.0.0.1:8000/ 。已有服务时不会重复启动。项目 start.bat 也可在前台运行。

全新环境运行 setup.ps1，安装 backend/requirements-lock.txt 中的Python依赖、执行npm ci并构建前端。本机验证Python 3.14、Node 24。密钥仅放在 backend/.env。

当前使用DeepSeek兼容Chat Completions接口。可配置 MODEL_BASE_URL、MODEL_API_KEY、MODEL_NAME、MODEL_RESPONSE_FORMAT、MODEL_TIMEOUT_SECONDS、MAX_ANALYSIS_CHARS。MODEL_TRUST_ENV=false 是本机模型连接设置，不关闭TLS证书验证。承诺对照要求模型支持JSON输出。

## 日常使用

1. 导入PDF、DOCX、图片，或粘贴合同。扫描页在本机OCR；混合页可选择整份OCR。
2. 核对文字、金额和对应服务。修改后保存新版本，再确认分析范围。
3. 同意发送脱敏正文与背景后生成真实报告。演示报告不会判断合同风险。
4. 使用上方工具。需要下次继续看时，进入报告历史，勾选本机保存并保存快照。

## 六项工具（2026-10-25）

| 工具 | 实际行为 | 边界 |
|---|---|---|
| 销售承诺对照 | 每行一条，最多30条；可导入聊天截图/PDF/DOCX；DeepSeek逐条比较并附合同原文 | 先核对销售文字并同意发送；不判断销售身份或截图真伪 |
| 退款试算 | 输入实付、已退、服务数量/单价/依据、违约金基数/比例；Decimal计算两情景并展示算式 | 不猜价格，不判断扣费效力；负余额不等于欠款；不计算利息或最终法律可退金额 |
| OCR | RapidOCR/ONNX CPU本机识别PNG/JPEG/WebP和扫描PDF | 金额、日期、否定词及表格需核对；不识别签章真伪；混合页可能需要整份OCR |
| 法规检索 | 四部官方法规/司法解释的46条合同、预付消费条文选编；完整条文、版本、日期、官方链接 | 不是全国法规库，不自动适用法律；更新固定来源失败时保留缓存并提示 |
| 版本比较 | 比较本次修订、另一份文件、历史快照，显示新增/删除/修改及双方位置 | 忽略空白；不比较图片、印章、版式；分页和OCR错误可能产生差异 |
| 报告历史 | 手动保存正文、报告、分析背景、沟通草稿及最近完成的承诺/退款结果；恢复、JSON导出、删除 | 恢复为副本，原快照不变；不保存原文件或未提交输入，不上传云端 |

- 消费者权益保护法（2013年修正）：https://www.samr.gov.cn/zfjcj/tzgg/art/2023/art_615af9ed6bcd4974bf853dd2e02bc663.html
- 消费者权益保护法实施条例（国务院令第778号）：https://www.mee.gov.cn/zcwj/gwywj/202403/t20240320_1068830.shtml
- 预付式消费司法解释（法释〔2025〕4号）：https://www.court.gov.cn/zixun/xiangqing/459321.html

2026-10-25通过官方网页读取并生成缓存，非模型编写。本机直接HTTPS访问这些官方页面出现SSL连接中断；当前可离线检索，在线更新会如实显示失败，未关闭证书验证。网页获取成功也不等同于确认法规最新有效，仍须核对修订、适用时间及具体案情。

## 数据保存

- 原文件在内存解析，不写磁盘，不发给模型。OCR模型随Python包装入，运行识别不联网。
- 未保存文档、版本、报告和工具结果在内存SQLite保留约1小时，关闭后端即丢失；最多20份临时文档。
- 只有主动保存才写入 data/history.sqlite3，包含合同文字等私密内容，未加密，保留至主动删除。可用 HISTORY_DB 指定其他本机路径，切勿公开分享数据目录。
- 清除临时文档不会删除历史；历史删除不可在应用中撤销。JSON导出是备份，目前不提供JSON导入。
- 主报告发送脱敏正文及背景；承诺对照发送脱敏正文及销售说法。规则脱敏不能发现所有姓名、地址等隐私，请先人工核对并确认发送。
- 法规检索只在本机进行，不发送检索词；更新仅请求固定官方URL，缓存不含合同。
- 应用日志不主动记录正文或密钥，启动器关闭访问日志。只监听127.0.0.1，无登录及多用户隔离，不适合直接公开部署。

## 限制与实现

单文件10MB，PDF最多80页，一次OCR最多20页。解析子进程最长180秒，超时终止；建议长扫描件拆分。图片最多3000万像素，OCR时限制尺寸。正文提取最多25万字符，主报告及承诺对照正文默认上限24000字符，不静默截断。DOCX展开最多30MB、2000个ZIP条目，页眉/页脚/嵌套表格/图片/批注/修订痕迹等仍未覆盖。版本比较两版共10万字符。历史列表显示最近200条。

引用使用编号片段，模型仅选择block_id/quote_id，后端回填原话与位置，拒绝虚假引用并有限重试。引用核验保证出处存在，不保证推理正确。法规原文保留官方措辞，其余报告尽量用通俗中文。

主要代码：backend/app/main.py（API）、analysis.py（主报告与引用）、contract_tools.py（承诺/退款/比较）、ocr.py及parsing.py（解析）、store.py及history.py（临时与历史）、legal.py及legal_corpus.json（法规选编）；frontend/src/ToolsPanel.vue（工具界面）、App.vue（三步流程）。

尚未实现：长合同分段及跨段分析、表格几何重建、保证识别手写、多用户认证、收费与公开部署。

## 验证

在backend目录运行测试；为避免系统临时目录权限问题，可为pytest提供项目内独立目录：

```powershell
$testTemp = Join-Path (Split-Path (Get-Location)) ('work\pytest-' + [guid]::NewGuid().ToString('N'))
..\.venv\Scripts\python.exe -m pytest tests -q --basetemp "$testTemp"
cd ..\frontend
npm.cmd run build
```

40项后端测试包含原有解析与引用回归、小数精度、输入边界、版本改动、历史恢复与版本校验、法规失败缓存回退、承诺虚假引用拦截、中文图片和扫描PDF真实OCR。浏览器用虚构材料验证DeepSeek承诺对照、退款试算、刷新后恢复、版本比较和法规原文展示。测试不是模型准确率或法律正确性认证。

examples/fictional-scan.png 和 examples/fictional-scan.pdf 可用于OCR演示。Starlette TestClient的httpx迁移弃用警告不影响运行。
